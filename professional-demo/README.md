# Sterling Advisory Group

A fictional Jamaican professional services website concept for the PMS Digital Solutions portfolio. Built with plain HTML, CSS, and vanilla JavaScript.

Open `index.html` locally to review. No build step, server, account, or backend is required. All page links are relative so the folder can also be deployed to a static host.

The consultation form validates fields and shows a demo confirmation. It never transmits or stores the entered information. Contact details and team profiles are fictional. Photography was generated for this concept and is stored locally in `assets/images`.

Pages: Home, About, Services, reusable Service Details, Insights, an article detail page, and Contact.
